# 역할 핸드오프

- 범위: setup-checkpoint / full-refactor / 단계 번호
- 역할과 읽을 문서: `agent-context/roles/<role>.md`
- 목표와 비목표:
- 확정 계약: 업무 규칙, API 호환성, 상태·시간·오류, 트랜잭션·락 순서
- 사용자 결정 근거: `DECISIONS.md`의 결정 ID와 답변. 미확정 결정이 있다면 의존 작업은 대기
- 소유 파일: 정확한 경로 목록
- 읽기 전용 파일 / 다른 담당자:
- 선행 작업과 병렬 가능 경계:
- 구현·검증 명령과 성공 기준:
- 이전 리뷰 지적과 재현 증거:
- 결과: 변경 파일, 동작, 검증 명령/exit code, 남은 위험·지적
- 사용자 질문 후보: 선택지, 각 영향, 의존 파일·단계. 임의 정책 채택 금지

공통 지시: 다른 에이전트와 같은 작업 트리를 공유한다. 타인의 변경을 되돌리지 말고
자신의 소유 파일만 수정한다. 같은 Java 파일을 병렬 수정하지 않는다. 커스텀 역할은
`.codex/agents/<역할>.toml`의 모델·추론 설정을 사용하고, `default`/`worker` 대체 호출은
별도 지정이 없으면 부모 설정을 상속한다. commit/push는 최종 검증과 독립 리뷰 뒤
오케스트레이터가 수행한다.
